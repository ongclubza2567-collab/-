# REDNOX — ชุดเริ่มต้นนำเว็บขึ้นออนไลน์และเปิด API ตัวอย่าง

## สิ่งที่ชุดนี้ทำได้
- แสดงหน้าเว็บ REDNOX ผ่าน URL สาธารณะเมื่อ Deploy สำเร็จ
- มี API ตรวจสุขภาพเซิร์ฟเวอร์ที่ `GET /api/health`
- มี API ข้อมูลร้านที่เปิดเผยได้ที่ `GET /api/public-config`
- มีโครงสร้างสำหรับต่อ API ในอนาคต

## ข้อจำกัดสำคัญ
ชุดนี้ยัง **ไม่ใช่ระบบรับเงินจริง** และยัง **ไม่ได้เชื่อม TrueMoney Open API** หรือฐานข้อมูลกลาง ตัวเว็บเดิมบันทึกข้อมูลหลายอย่างใน `localStorage` จึงเป็นข้อมูลเฉพาะเบราว์เซอร์เครื่องนั้น ไม่ได้แชร์ระหว่างลูกค้าทุกคน/ทุกอุปกรณ์ และระบบแอดมินเดิมยังไม่ใช่การยืนยันตัวตนฝั่งเซิร์ฟเวอร์ ห้ามใช้รับเงินจริงหรือเก็บข้อมูลลูกค้าจริงจนกว่าจะพัฒนาระบบบัญชีผู้ใช้ ฐานข้อมูล และสิทธิ์แอดมินฝั่งเซิร์ฟเวอร์ให้เสร็จ

## วิธีนำขึ้นออนไลน์ด้วย Render
1. แตกไฟล์ ZIP นี้ลงโฟลเดอร์บนคอมพิวเตอร์
2. เข้า GitHub แล้วสร้าง repository ใหม่ แนะนำตั้งเป็น Private ระหว่างพัฒนา
3. อัปโหลดไฟล์/โฟลเดอร์ทั้งหมดในชุดนี้เข้า repository แล้วกด Commit changes
4. เข้า Render Dashboard แล้วเลือก **New → Web Service** จากนั้นเชื่อม GitHub และเลือก repository นี้
5. ตั้งค่า Build Command เป็น `npm install` และ Start Command เป็น `npm start` (ถ้า Render อ่านจาก `render.yaml` ได้ ให้ตรวจว่าค่าตรงกัน)
6. กด Deploy เมื่อเสร็จจะได้ URL ลักษณะ `https://ชื่อบริการ.onrender.com`
7. เปิด URL นั้นเพื่อดูหน้าเว็บ และเปิด `https://ชื่อบริการ.onrender.com/api/health` เพื่อทดสอบ API

หมายเหตุ: แพ็กเกจฟรีของบริการโฮสต์อาจหยุดทำงานชั่วคราวเมื่อไม่มีคนใช้งาน และอาจใช้เวลาตื่นขึ้นเมื่อเปิดครั้งแรก

## วิธีให้ Google ค้นหาเว็บเจอ
1. Deploy ให้เว็บมี URL สาธารณะก่อน
2. เปิด Google Search Console แล้วกด Add property → URL prefix
3. ใส่ URL แบบเต็ม เช่น `https://ชื่อบริการ.onrender.com`
4. ทำตามวิธียืนยันเจ้าของเว็บที่ Google แสดง ถ้าเลือก HTML file ให้วางไฟล์ยืนยันใน `public/` แล้ว commit/deploy ใหม่ ถ้าเลือก HTML meta tag ให้วาง tag ที่ Google ให้ในส่วน `<head>` ของ `public/index.html` แล้ว deploy ใหม่
5. หลังยืนยันแล้ว ใช้ URL Inspection ใส่ URL หน้าแรก แล้วเลือก Request indexing

การส่งคำขอไม่ได้รับประกันว่าจะขึ้น Google ทันที Google ต้องใช้เวลาคลานและจัดทำดัชนี และไม่ได้รับประกันว่าจะรับทุก URL

## วิธีต่อ TrueMoney / PromptPay API จริง
1. สมัคร/ขอสิทธิ์บริการ TrueMoney Open API จากช่องทางทางการ และรับเอกสาร Webhook/API ที่ตรงกับบัญชีของคุณก่อน
2. หลังได้สิทธิ์ ให้ใช้เอกสารทางการกำหนด URL webhook, วิธีตรวจลายเซ็น/โทเคน, รูปแบบข้อมูลรายการ และเงื่อนไขของธุรกรรม
3. เขียน endpoint ฝั่งเซิร์ฟเวอร์ให้รับเฉพาะ event ที่ตรวจสอบแหล่งที่มาได้ ตรวจยอดเงิน สถานะ และเลขธุรกรรมซ้ำ ก่อนบันทึกลงฐานข้อมูลกลาง
4. เก็บ API secrets ในหน้า Environment Variables ของผู้ให้บริการโฮสต์เท่านั้น ห้ามใส่ใน `index.html`, JavaScript ฝั่งหน้าเว็บ, GitHub repository หรือส่งให้คนอื่น
5. ต้องมีฐานข้อมูลกลางและระบบป้องกันการให้เครดิตซ้ำ ก่อนเปิดรับเงินจริง

ในขณะนี้ `/api/payments/*` จะตอบกลับ 503 โดยตั้งใจ เพื่อไม่ให้เข้าใจผิดว่าได้เชื่อมรับชำระเงินจริงแล้ว อย่าสร้างยอดเงินจากการรับข้อมูลที่ผู้ใช้ส่งเองโดยไม่มีการตรวจสอบจาก provider
